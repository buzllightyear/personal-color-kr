# 불변식 (Invariants)

> 이 프로젝트에서 **깨지면 안 되는 계약** 목록 — 코드 언어가 아니라 운영자 언어로 적는다.
> 운영자(비개발자)는 에이전트 산출물을 코드 레벨에서 검증할 수 없다. 그래서 이 목록이
> 검증의 기준선이다: 코드는 못 읽어도 이 문서는 읽고 판단할 수 있어야 한다.
>
> **에이전트 의무 (CLAUDE.md "Operator protocol" 참조):** 변경이 아래 항목에 *닿기만 해도*
> 작업 보고에 명시한다 — "불변식 N에 닿음, 위반 아님/위반임 + 근거". 조용한 통과 금지.
>
> **갱신 규칙:** 항목 추가·수정·삭제는 운영자 결정으로만 한다. 에이전트는 후보를 제안만 한다.

## 프라이버시 / 신뢰

1. **원본 셀피는 서버에 절대 저장하지 않는다.** 저장되는 것은 워터마크가 입혀진 생성
   결과물뿐이다. (zero-PII — 프라이버시를 경쟁 포지션으로 삼는 moat의 일부)
2. **얼굴 데이터를 수집·축적하지 않는다.** 축적해도 되는 행동 데이터는 저장/공유/삭제
   같은 선호 신호뿐이다.
3. **갤러리 이미지는 인증 + 소유권 확인을 거친 엔드포인트로만 나간다.** 공개 URL·presigned
   URL로 노출하지 않는다.

## 제품 구조

4. **recipe의 `prompt_template`은 서버 밖으로 절대 나가지 않는다.** 클라이언트 응답, 로그,
   에러 메시지 어디로도. (복제 불가능한 moat 레이어 — 노출되면 output-clone이 가능해진다)
5. **진단(퍼스널컬러) 출력은 이미지 생성 파이프라인에 들어가지 않는다.**
   (`{personal_color_modifier}`는 의도적으로 미확장 유지) — 피봇으로 진단이 코드에서
   제거되는 날까지 유효하다.
6. **core-ts 퍼널 콘텐츠는 동결.** 화면별 콘텐츠 변경은 앱 레이어 오버라이드로만 한다.

## 운영 / 배포

7. **`apps/mobile/app.config.ts`의 `updates.url`은 제거 금지.** 제거하면 OTA 업데이트가
   조용히 죽고 JS-only 변경마다 네이티브 재빌드가 강제된다. (상세: CLAUDE.md, #101)
8. **비용이 발생하거나 외부로 공개되는 동작은 운영자 확인 후에만 실행한다.** 배포, 스토어
   제출, 유료 외부 API 사용 확대, 외부 서비스로의 데이터 전송이 여기 해당한다.
