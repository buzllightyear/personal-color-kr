## 코드베이스 도출 근거 (codebase derivation)

이 제목의 모든 어휘는 기존 코드베이스에서 직접 가져왔어요. 새로 지어낸 표현이 없어요.

| 제목 구성요소 | 출처 (소스) |
| --- | --- |
| `퍼스널 컬러` | `packages/core-ts/src/funnel/screens.ts` — `welcome_hook.headline` "내 퍼스널 컬러로...", `scan_option_select` 메인 스캔 라벨 "퍼스널 컬러 진단" |
| `진단` | `welcome_hook.subhead` "1분 **진단**으로...", `scan_option_select` CTA "퍼스널 컬러 **진단**" |
| `셀카가 빛나요` | `welcome_hook.headline` "내 퍼스널 컬러로 **셀카가** 한 장 더 **빛나**도록" — 핵심 가치 제안(value prop)을 해요체 종결형 `빛나요`로 변환 |

- **value_prop**: `퍼스널 컬러 진단으로 셀카가 더 빛난다` (= `welcome_hook`의 hook 메타데이터 `personal_color_diagnosis`)
- **narrative_position**: `welcome_hook` (퍼널 1단계, screenshot 1과 동일한 진입 가치 제안)
- **target audience**: 20–30대 한국 여성 셀카 사용자 — "셀카가 빛나요"가 셀카+퍼스널 컬러 도메인을 직접 호명

## 어조 검증 (해요체)

- `빛나요` = 동사 `빛나다` + 해요체 종결어미 `-아요` → 해요체 ✅
- 반말(예: `빛나`) 아님 ✅
- 존댓말(예: `빛납니다`) 아님 ✅
- 기존 퍼널 카피(`괜찮아요`, `정확해요`, `공개돼요`, `있어요`)와 동일한 해요체 레지스터 유지 ✅
