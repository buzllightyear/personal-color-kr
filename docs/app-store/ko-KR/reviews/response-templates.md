# App Store 리뷰 응답 템플릿 (Review Response Templates) — ko-KR

| 항목 | 값 |
| --- | --- |
| `file_path` | docs/app-store/ko-KR/reviews/response-templates.md |
| `file_type` | review_template |
| `locale` | ko-KR |
| `brand_voice` | 해요체 (semi-formal) |
| `대상 카테고리` | positive · negative-bug · negative-feature · neutral (4종) |
| `대상 사용자` | 20~30대 한국 여성 셀카 사용자 |

> App Store Connect의 **고객 리뷰 응답(Developer Response)** 필드에 그대로 붙여넣을 수 있는 템플릿이에요.
> 모든 응답은 기존 펀널 화면 카피와 동일한 **해요체** 톤으로 작성했어요(반말·존댓말 사용 금지).
> `[TODO: ...]`와 `{대괄호}` 표시는 응답을 올리기 전에 사람이 채우거나 상황에 맞게 다듬어 주세요.
> 응답 운영 절차(SOP)는 이 문서 하단 "운영 가이드"와 `README.md`의 검수 체크리스트를 함께 참고해 주세요.

---

## 1. positive — 긍정 리뷰 응답

> `response_category`: positive
> 별점이 높거나 진단·편집 결과에 만족한 리뷰에 사용해요. 감사 인사 + 친구 추천 코드 공유 유도를 담아요.

```text
{닉네임}님, 따뜻한 리뷰 정말 고마워요! 🌸
내 퍼스널 컬러로 셀카가 한 장 더 빛났다니 저희도 너무 기뻐요.
봄·여름·가을·겨울, 계절마다 어울리는 컬러로 새 셀카도 자주 남겨보세요.
마음에 드셨다면 친구 추천 코드로 친구와 함께 내 컬러를 찾아보는 것도 추천드려요.
앞으로도 매월 새 큐레이션으로 곁에서 거들게요. 또 만나요!

— 퍼스널 컬러 큐레이션 팀 드림
```

## 2. negative-bug — 버그/오류 리뷰 응답

> `response_category`: negative-bug
> 스캔 실패, 앱 종료, 결과 오류 등 기술적 문제를 겪은 리뷰에 사용해요. 사과 + 원인 확인(Sentry 오류 추적) + 재현 정보 요청을 담아요.

```text
{닉네임}님, 불편을 드려서 정말 죄송해요. 😢
진단이 매끄럽게 끝나야 하는데 그러지 못했다니 마음이 쓰여요.
저희는 앱에서 발생한 오류를 자동으로 수집해 원인을 빠르게 찾고 있어요. 다만 더 정확히 확인하려면 몇 가지가 필요해요.
• 사용 중인 기기와 iOS 버전
• 문제가 생긴 화면(예: 셀카 업로드, AI 24개 포인트 스캔, 결과 화면)
• 오류가 나타난 대략적인 시각
괜찮으시면 위 내용을 [TODO: 고객지원 이메일 또는 URL]로 보내주세요. 확인 후 꼭 해결해서 다시 안내드릴게요.
번거롭게 해드려 다시 한번 죄송해요. 빠르게 바로잡을게요.

— 퍼스널 컬러 큐레이션 팀 드림
```

## 3. negative-feature — 기능 불만/요청 리뷰 응답

> `response_category`: negative-feature
> 원하는 기능이 없거나 기대와 달랐다는 리뷰에 사용해요. 공감 + 현재 제공 기능 안내 + 의견 반영 의지를 담아요.

```text
{닉네임}님, 솔직한 의견 들려주셔서 고마워요.
기대하신 부분을 충분히 채워드리지 못한 것 같아 아쉬워요.
지금은 1분 퍼스널 컬러 진단과 그 컬러에 맞춘 편집, 매월 새 큐레이션을 중심으로 챙겨드리고 있어요.
말씀해주신 {요청한 기능}은 팀에서 함께 검토해볼게요. 더 좋은 방향이 있다면 다음 업데이트에 담아볼게요.
혹시 더 바라는 점이 있다면 [TODO: 고객지원 이메일 또는 URL]로 편하게 들려주세요.
귀한 의견 덕분에 더 나아질 수 있어요. 정말 고마워요!

— 퍼스널 컬러 큐레이션 팀 드림
```

## 4. neutral — 중립/일반 문의 리뷰 응답

> `response_category`: neutral
> 별점이 중간이거나 단순 질문·후기인 리뷰에 사용해요. 감사 + 핵심 사용법 안내 + 추가 문의 안내를 담아요.

```text
{닉네임}님, 앱을 사용해주시고 후기까지 남겨주셔서 고마워요.
혹시 더 잘 활용하고 싶으시다면, 정면·자연광·민낯에 가까운 셀카 1장으로 진단하면 가장 정확한 컬러를 받아볼 수 있어요.
진단 후에는 봄 웜톤·여름 쿨톤·가을 웜톤·겨울 쿨톤 중 내 카테고리에 맞춘 편집과 메이크업·코디 가이드도 함께 확인해보세요.
궁금한 점이 있으면 언제든 [TODO: 고객지원 이메일 또는 URL]로 물어봐 주세요.
앞으로도 더 나답게 빛나는 셀카를 곁에서 거들게요!

— 퍼스널 컬러 큐레이션 팀 드림
```

## 운영 가이드 (Review Response SOP)

| 단계 | 내용 |
| --- | --- |
| 1. 분류 | 새 리뷰를 positive / negative-bug / negative-feature / neutral 중 하나로 분류해요. |
| 2. 선택 | 위 4개 템플릿 중 맞는 것을 골라요. |
| 3. 개인화 | `{닉네임}`·`{요청한 기능}` 등 중괄호 변수를 실제 내용으로 바꿔요. |
| 4. TODO 채우기 | `[TODO: 고객지원 이메일 또는 URL]`을 `urls.md`의 support-url과 동기화해 채워요. |
| 5. 톤 확인 | 해요체 일관성을 확인하고(반말·존댓말 금지) 24~48시간 내 응답해요. |
