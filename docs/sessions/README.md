# docs/sessions/ — 세션/회의 archive

**무엇:** 개발 세션·논의의 **append-only, 날짜별** 기록. "YYYY-MM-DD에 우린 이렇게 생각했다"를 박제한다.

**SSoT 아님 (중요):** 이건 `docs/STRATEGY.md`(궤적)·`CLAUDE.md`(현재상태)·`docs/decisions/`(ADR)·auto-memory 같은 **현재-진실 문서가 아니다.** 날짜 박힌 기록은 그 시점의 사고를 담을 뿐 — **현재 입장으로 인용 금지.** 그래서 archive는 **drift하지 않는다**(나중에 방향이 바뀌어도 과거 기록은 여전히 정확: 그땐 그렇게 생각한 게 사실이니까). 현재 진실이 필요하면 SSoT를 봐라.

**왜:** 컨텍스트 컴팩션이 *논의의 결*(저울질한 옵션·버린 길·어디서 갈렸나)을 몇 시간 안에 지운다. SSoT는 *결정*만, git은 *변경*만 남긴다 — 그 사이의 *추론*은 여기에만 남는다.

**형태:**
- 파일: `YYYY-MM-DD-<주제-kebab>.md`. 한 세션이 여러 주제면 나눠도 됨.
- **distilled — 원문 transcript 아님.** 검색성 우선(날짜·주제·greppable).
- 항목 템플릿:
  ```
  # YYYY-MM-DD — <주제>
  ## 논의            — 뭘 다뤘나
  ## 옵션 저울질      — A vs B vs C, 트레이드오프
  ## 결정 / 미결      — 결정된 것 + 반영처(SSoT/커밋) · **미결(OPEN):** 다음에 이어갈 것
  ## 왜 / 교훈        — 근거
  ## 관련            — 커밋·PR·메모리·SSoT 포인터
  ```

**실패모드 — write-only(아무도 안 읽음):** 그래서 완전성보다 **검색성.** 길게 쓰지 말고 결·근거만. 안 읽힐 분량이면 줄여라.

**층위:** archive("그때 뭘 생각했나", 버린 옵션 포함) ⊃ SSoT("지금 뭐가 참인가", 결정만). 결정의 SSoT-반영은 *별개의 나중 단계*다 — archive는 반영 여부와 무관하게 그때의 사고를 남긴다.

**언제 (트리거):** *시계가 아니라 사용자의 pre-close 행동.* "세션 끝"의 유일하게 신뢰 가능한 관측자는 사용자다 — 에이전트는 그 시점을 못 본다(다음 턴이 올지 모름). 그래서:
- **주 트리거 = 닫기 전 사용자가 신호** ("기록하고 닫자"). 사용자가 한 줄, **에이전트가 증류**(세션을 in-context로 보유하므로 비용은 에이전트 쪽).
- **보조 = 에이전트의 턴-안 플래그.** 결정/OPEN이 닫히는 *그 순간* "archive 후보?" 표시 — 컴팩션이 결을 지우기 전에. pre-close를 깜빡해도 substance는 남는다.
- **고정 주기·"매일"·자동 "세션끝" = 없음.** 그런 *관측 가능한 단일 시점*이 없다(Claude Code Stop 훅은 *매 턴* 끝에 떠 세션끝이 아님). 사소한 세션 → 항목 0(D2 신호게이트와 동형).
- **승급 신호:** pre-close를 반복적으로 깜빡해 결정-스레드를 놓치면 → 그때 commit-넛지/Stop-훅 도입(측정 후, 과잉규율 회피).
