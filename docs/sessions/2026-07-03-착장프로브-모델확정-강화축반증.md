# 2026-07-03 — fal eval 2라운드: stage-0 → 모델 확정 → 착장 프로브 (강화-축 반증 · ArcFace 불성립)

## 논의
전날 출고한 블라인드 eval 하네스(PR #127)의 **첫 실전 2라운드**. ① 옷 단독 stage-0(36셀, $1.46) → ② 운영자 모델 확정 → ③ 트렌드 무드 레퍼런스 증류 → ④ 착장 프로브(48셀, $1.90). 총 지출 ~$3.36, 매 실행 견적-승인 게이트(불변식 #8) 준수.

## 진행 결
- **stage-0 (옷 단독):** nanobanana2lite 3.33(운영자 요청으로 당일 로스터 추가, `google/nano-banana-2-lite/edit` 검증) > seedream45 2.67 > 나머지. 아무도 GARMENT_FLOOR(3.5) 못 넘음. 입력 유형별 승자 갈림(착용샷 하의=seedream, 니트·플랫=lite). 채점 규칙 신설: **solo 출력에 인물 등장 = 옷 분리 실패 → garment_fidelity ≤2 + notes "인물"** (운영자 결정).
- **모델 확정 (운영자, stage-0 근거):** "이 정도 측정으로도 확정 가능 — lite + seedream45, 적당한 퀄리티·적당한 가격" → `FINALISTS` 코드화. 착장 능력은 의도적으로 다음 라운드로 이월.
- **트렌드 무드 증류:** 운영자가 trend_refs/ 5장 제공(심즈 거울셀피·0.5x 셀피·하이앵글 캔디드·워킹 파파라치·스티커 셀피). 공통 문법 = **오프가드 캔디드 질감 + 그래픽/텍스트 오버레이**. 후자는 생성이 아니라 `format_template` 컴포지팅 소관(§7-D #2와 정합) — 생성은 구도·조명·폰스냅 질감만. → garment_scene(워킹 캔디드)/garment_format(0.5x 셀피) realistic 프롬프트 운영자 승인, REFERENCE로 시트에 연결.
- **착장 프로브 (2모델×2강화×3옷×2셀피, 규모 반축소는 운영자 지시):** 반전 —
  - **lite**: 최상픽 14/17 (시도당 성공률 58%) — 착장·무드 압승, 단 ArcFace 0.46.
  - **seedream45**: 픽 2/24 (10%) — 옷·무드를 못 바꿈. **착장 임무 탈락** (재시도로도 못 살림).
  - **ArcFace 불성립**: 픽(0.505) < 비픽(0.717) **역상관**. 운영자 확인 — seedream의 0.85짜리도 "대부분 딴사람". 전신 캔디드 샷에서 임베딩 유사도 ≠ 사람 눈 판정 → **정체성 자동 게이트 도출 실패**, 판정자는 당분간 사람 눈.
- **후속 발견 (운영자 관찰 → 정정 → 확정):** ① **의도 슬롯** — 모델이 옷 핏을 착용자 성별·체형에 맞춰 각색(남성 박시 티→여성에게 허리라인 핏). "원핏 고정 vs 각색 허용"은 미정의 의도 입력 — 제품 결정 필요. ② **seedream = 레퍼런스 인물 얼굴 앵커링** — 옷 사진 속 인물 얼굴로 출력(사람 있는 옷 0/16 전멸, 사람 없는 플랫샷에서만 픽 2 = 셀피 앵커 복원 힌트). 에이전트가 "타투·안경 동일=같은 사람"으로 반박했다가 운영자 정정("부착물은 복사되는 토큰, 얼굴은 네가 못 보는 것") — **얼굴 판정은 운영자 눈만 유효** 원칙 확립([[face-identity-judgment-operator-only]] 메모리). → **하드 룰: 옷 레퍼런스는 사람 없는 컷** (정규화 단계 근거 추가). ③ **모델별 최적 프롬프트 존재** — 고수형(seedream: edit-forcing 채찍 필요) vs 재해석형(lite: 정체성·핏 고삐 필요), 선별 단계의 동일-프롬프트(blocked) 설계는 옳았으나 배치 단계엔 모델별 처방.
- **강화-축 반증 (2라운드 일관):** stage-0 none 2.33 vs profile 2.17, 착장 none 9픽 vs profile 5픽. §10-B "프로필 주입=품질" thesis **생성 축에서 반증** → 주입 기본 off, 프로필 가치는 DB적립·칩UX·커머스로 이동 (STRATEGY §10-B에 깎아 반영).
- **재검(test-retest) 2회차:** 1라운드 |Δ|=0.25(우수) vs 2라운드 |Δ|=1.6(5쌍 중 2쌍 불일치) — 등급식 채점은 안정, "최상 하나 고르기" 이진 판정은 흔들림. 채점 방식 자체가 신뢰도 변수라는 실측.

## 왜 / 교훈
- **"측정기 먼저 보정" 원칙의 실증**: ArcFace 임계값(0.55)을 믿고 자동 게이트를 깔았으면 운영자 눈과 반대로 걸렀다. README의 bar-calibration 경고("임계값은 라벨 대조 전엔 죽은 숫자")가 정확히 적중 — 이번엔 보정 시도가 도구 자체를 기각.
- **채점 프로토콜이 신뢰도를 만든다**: 같은 채점자가 등급식(|Δ|=0.25)과 이진 픽(|Δ|=1.6)에서 다른 일관성 — 검증자-없는-영역 ②의 대응책(재검 쌍둥이)이 첫 실전에서 "어떤 채점 방식이 믿을 만한가"까지 알려줌.
- **싼 프로브의 정보 효율**: $3.36으로 — 모델 2종 확정→1종 착장 탈락, thesis 1개 반증, 측정기 1개 기각, 성공률 실측(58%). 풀 스윕($51) 전에 갈림길들이 거의 다 닫힘.
- **트리거(이 회의록):** 착장 프로브 해석 스레드가 닫히는 순간(운영자 "(ㄴ) 대부분 딴사람" 확인) 에이전트 in-turn 플래그.
